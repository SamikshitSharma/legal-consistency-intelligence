4. One important adjustment I made to our earlier plan

I deliberately made the prompt say:

"The attached v1.2.2 files are the source of truth."

rather than duplicating the entire JSON schema into the Antigravity prompt.

That's intentional.

We just spent multiple review cycles eliminating tiny contradictions between the spec and system prompt. If we copy the schema into a third document, we create a third source of truth and can recreate the exact problem we just eliminated.

Antigravity should read the PDFs and implement against them.

The implementation prompt defines engineering behavior and acceptance criteria; the v1.2.2 documents define AI contract behavior.

That separation is cleaner.
